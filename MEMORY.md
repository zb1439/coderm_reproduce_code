## LiveCodeBench Official Evaluation
- Official repo: `github.com/LiveCodeBench/LiveCodeBench`
- Dataset: `livecodebench/code_generation_lite` on HuggingFace
- Custom evaluator: `python -m lcb_runner.runner.custom_evaluator --custom_output_file X --scenario codegeneration`
- Input format: `[{"question_id": "3228", "code_list": ["code1", ...]}]`
- Task IDs in this project: 3228-3606 (168 tasks)

## Data Format Reference

### func.jsonl (raw solutions, used by evaluate.py for LiveCodeBench)
```json
{"task_id": "3228", "solutions": ["from string import *\n...class Solution:...", ...]}
```
- 100 solutions per task, 168 tasks, solutions are raw strings with import preamble

### anno.jsonl (annotated, used by calculate_result.py)
```json
{"task_id": "3228", "solutions": [{"sol_id": 0, "code": "class Solution:...", "result": "pass"}, ...]}
```
- code field: cleaned class-only; result field: "pass"/"fail" from official LiveCodeBench eval

### Execution matrix result (generated by evaluate.py)
```json
{"task_id": "3228", "sol_id": 0, "ut_id": 0, "result": "pass", "details": {...}}
```
